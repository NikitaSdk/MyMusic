# MyMusic — личный музыкальный плеер для iPhone

Учебный проект (лабораторная работа) для личного некоммерческого использования.
Поиск музыки на YouTube, прослушивание онлайн, скачивание для офлайна,
медиатека, плейлисты, фоновое воспроизведение с выключенным экраном.

## Стек
- Swift 5 + SwiftUI (iOS 17+)
- AVFoundation (AVPlayer) — воспроизведение, фоновый режим `UIBackgroundModes: audio`
- MediaPlayer — экран блокировки, Пункт управления, кнопки наушников
- SwiftData — медиатека и плейлисты
- YouTubeKit — получение ссылки на аудиопоток
- InnerTube (внутренний API YouTube) — поиск, без ключей
- XcodeGen + GitHub Actions (macOS) — сборка .ipa без своего Mac

## Структура
```
project.yml                   описание проекта (из него XcodeGen делает .xcodeproj)
.github/workflows/build.yml   автосборка .ipa на GitHub
MyMusic/App/                  точка входа
MyMusic/Models/               Song, Track, Playlist, операции медиатеки
MyMusic/Services/             YouTube, плеер, скачивание, монитор сети
MyMusic/Views/                экраны: поиск, медиатека, плейлисты, плеер
```

## Как собрать .ipa
1. Создать на GitHub **публичный** репозиторий `MyMusic` (для публичных Actions бесплатны).
2. Загрузить в него содержимое этой папки (вместе с папкой `.github`).
3. Вкладка **Actions** → «Build IPA» запускается сама после загрузки
   (или вручную: Run workflow). Сборка ~5–10 минут.
4. Открыть завершённую сборку → внизу «Artifacts» → скачать `MyMusic-ipa`
   (это zip, внутри `MyMusic.ipa`).

## Как установить на iPhone (бесплатно)
1. На Windows установить iTunes (версия с сайта Apple, не из Microsoft Store) и **Sideloadly** (sideloadly.io).
2. Подключить iPhone кабелем, нажать «Доверять».
3. В Sideloadly перетащить `MyMusic.ipa`, ввести свой Apple ID → Start.
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
5. iOS 16+: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл, перезагрузка.
6. Раз в 7 дней — повторить шаг 3 (данные и скачанная музыка сохраняются).
   Чтобы обновлять без ПК — настроить SideStore (sidestore.io).

## Как пользоваться
- **Поиск**: ввести запрос, нажать на трек — играет. Удерживать трек — меню:
  в медиатеку, скачать, добавить в плейлист.
- **Медиатека**: сохранённые треки, фильтр «Скачанные» для офлайна.
- **Плейлисты**: «+» — создать, внутри — порядок треков и удаление (кнопка «Править»).
- Без интернета играют только скачанные треки (остальные полупрозрачные).

> Примечание: получение аудио в обход официального плеера нарушает правила
> использования YouTube. Проект учебный, только для личного использования.
